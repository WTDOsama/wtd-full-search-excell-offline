## ✨ المميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🔍 **بحث فوري** | بحث ذكي مع تمييز النتائج (Highlight) أثناء الكتابة |
| 📁 **دعم متعدد** | يدعم `.xlsx` و `.xls` و `.csv` |
| 🌐 **عربي بالكامل** | واجهة RTL متكاملة مع خط Tajawal |
| ⚡ **بدون إنترنت** | يعمل Offline بعد التحميل الأول (PWA-Ready) |
| 🎨 **وضعين** | الوضع الفاتح والوضع الليلي (Dark Mode) |
| 📱 **متجاوب** | يعمل على الجوال والتابلت والديسكتوب |
| 💾 **حفظ تلقائي** | يحفظ البيانات في LocalStorage للاستخدام لاحقاً |
| 📤 **تصدير** | تصدير النتائج إلى CSV أو JSON |
| ✏️ **تعديل وحذف** | تعديل السجلات وحذفها مباشرة من الواجهة |

## 🚀 طريقة الاستخدام

### الاستخدام السريع (Online)
1. افتح الملف `index.html` في أي متصفح حديث
2. اسحب ملف Excel/CSV إلى منطقة الرفع **أو** اضغط "اختيار ملف"
3. ابدأ البحث فوراً في حقل البحث 🔍

### الاستخدام المحلي (Offline)
```bash
# 1. استنساخ المستودع
git clone https://github.com/username/excel-search-pro.git

# 2. الدخول للمجلد
cd excel-search-pro

# 3. فتح الملف (أو استخدم Live Server)
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
